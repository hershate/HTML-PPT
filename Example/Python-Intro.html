📜 Python 简史

从荷兰圣诞假期的个人项目，到全球最受欢迎的编程语言之一

1989 年 12 月

Guido van Rossum 在荷兰阿姆斯特丹开始开发 Python，作为 ABC 语言的继承者

1991 年

Python 0.9.0 发布——已包含异常处理、函数和核心数据类型

1994 年

Python 1.0 正式发布，引入 lambda、map、filter 等函数式特性

2000 年

Python 2.0 发布——加入列表推导式、垃圾回收、Unicode 支持

2008 年

Python 3.0 发布——重大升级，不向后兼容（"清理工具箱"）

2020 年

Python 2 正式退役，Python 3 成为唯一版本 · TIOBE 年度编程语言

2024 至今

Python 3.13 发布 · 全球开发者超 1500 万 · AI/ML 领域第一语言
